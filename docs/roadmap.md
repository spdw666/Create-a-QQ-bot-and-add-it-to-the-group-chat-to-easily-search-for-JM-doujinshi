# JM娘产品路线图

本路线图以“稳定可用、群内公平、隐私最小化”为优先级。完成项以实际可用和离线测试为准，不把实验性设想写成已经上线的功能。

## 已完成：个人任务底座

- [x] 搜索、榜单、识图结果按“群 + 用户”隔离。
- [x] `@我 下载 3`、`@我 详情 3` 操作自己的结果序号。
- [x] SQLite 保存任务状态与最近下载记录，重启后可查询。
- [x] `我的任务`、`我的下载`、`重发 N`。
- [x] 单用户最多 2 个执行中/排队任务；`取消`只取消自己的最近任务。

## 下一步：下载体验

- [ ] 指定章节下载：`下载 JM123456 第 2-5 章`，并明确章节名称和实际页数。
- [ ] 超大 ZIP 自动分卷，以及可配置的单卷大小。
- [ ] 缓存保留策略、剩余磁盘空间预警和可观测的清理结果。
- [ ] 管理员任务诊断：按任务 ID 查看阶段、耗时和失败原因。

## 后续：识图与订阅

- [ ] 识图结果提供来源和置信度说明；“都不对”进入不同的深度识别路径。
- [ ] 收藏作品、作者和标签；更新采用摘要推送，避免刷屏。
- [ ] 管理员开关、速率限制和可审计的健康检查。

## 设计约束

1. 不提交密钥、密码、Cookie、真实下载内容或用户数据库。
2. 新命令先做群内误触发评估；可能触发下载的短命令默认需要 @机器人。
3. 所有影响下载队列的功能都必须兼顾取消、重启恢复和多用户公平性。
4. 每项上线功能至少有离线测试，并在生产服务启动后复核。
